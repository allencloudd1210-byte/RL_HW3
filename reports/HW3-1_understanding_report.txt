HW3-1 Understanding Report: Naive DQN for Static Mode

1. Task summary
This part implements a basic Deep Q-Network for an easy static Gridworld environment. The environment is deterministic: the player, goal, pit, and wall positions are fixed every episode. This matches the "static mode" setting in the DRL in Action Chapter 3 reference.

2. Environment
The state is encoded as four 4x4 one-hot layers: Player, Goal, Pit, and Wall. After flattening, each state is a 64-dimensional vector. The action space has four actions: up, down, left, and right. Reaching the goal gives +10, falling into the pit gives -10, and every non-terminal move gives -1.

3. Naive DQN
The Q-network takes the 64-dimensional state vector and outputs four Q-values, one for each action. During training, epsilon-greedy exploration is used: early episodes choose many random actions, and later episodes mostly choose the action with the largest predicted Q-value. The target value is:

    y = reward + gamma * (1 - done) * max_a Q(next_state, a)

Because this is the naive DQN version, the same online network is used for both the current Q-value and the bootstrap target. No target network is used in HW3-1.

4. Experience replay buffer
The replay buffer stores transitions in the form (state, action, reward, next_state, done). Instead of training only on the newest transition, the algorithm randomly samples a minibatch from the buffer. This reduces correlation between consecutive steps and reuses previous experience, which makes training more stable than purely online single-step updates.

5. ChatGPT clarification notes
In this conversation, ChatGPT helped clarify that the static Gridworld is suitable for the easy environment requirement, that the replay buffer should store terminal transitions for both winning and losing outcomes, and that HW3-1 should remain a naive DQN without a separate target network.

6. Run result
The implementation is in hw3_1/naive_dqn_static.py and the environment is in hw3_1/gridworld.py. I ran:

    python -m hw3_1.naive_dqn_static --episodes 1500 --eval-episodes 50 --seed 7

The greedy evaluation after training achieved 50 wins out of 50 static-mode episodes, so the win rate was 100%. The average episode length was 7 moves, with one learned action sequence:

    down, down, left, left, left, up, up

This path avoids the pit and wall and reaches the goal. The run saved metrics to outputs/hw3_1_static_metrics.json, training history to outputs/hw3_1_static_training.csv, and model weights to outputs/hw3_1_static_dqn.pt.
